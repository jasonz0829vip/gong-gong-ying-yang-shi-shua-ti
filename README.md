# 公共营养师刷题

手机刷题页：顺序练习、随机练习、专项练习、模拟考试、错题本、收藏、到期复习。进度、错题本、收藏只保存在使用者自己的手机浏览器里（localStorage），多人使用互不影响。

题目为上海交通大学医学院公共营养师培训内部资料，请勿外传。

## 部署

纯静态单页 `index.html`（题库已内联，零外部资源），GitHub Pages 直接托管即可。

## 题库

- 共 1401 题：理论单选 835、理论多选 243、技能考核 323（单选 142 + 多选 181）
- 模拟考试按真实格式：理论 85 题 / 90 分钟（单选 70×1 分 + 多选 15×2 分），技能 25 题 / 60 分钟（每题 4 分），100 分满分、60 分及格
- 多选判分：至少 2 个正确答案，多选、少选、错选均不得分
- 解析分三类：资料原解析 257 道；AI 按三级教材现写 1125 道（已标注“解析由 AI 生成，仅供参考，以教材为准”）；19 道“解析待补充”
